## 정리
- man은 명령어, 설정 파일, 시스템 기능의 공식 설명서를 터미널에서 바로 보는 명령어 
- 설명서 파일은 /usr/share/man/ 아래에있고 보통 각 패키지가 설치될때 설명서도 함께 설치
- man 조작 방법 space 다음 페이지, b 이전 페이지, 방향키 위 아래 한 줄 이동,/단어 아래로 검색, n N 검색중 다음,이전 단어 검색, q 종료
- man 내용은 less라는 패이지 보기 프로그램으로 보여줌
- 섹션 번호 개념 같은 이름이더라도 명령어인지, 설정파일인지, 시스템 콜인지에 따라 설명서가 있고 번호로 나눈다.
- 번호를 생략하면 낮은 번호부터 찾아서 처음 나온것을 보여줌
- 섹션 번호 1.일반 사용자 명령어, 2.시스템 콜(커널 기능), 3.라이브러리 함수, 4.장치 파일, 5.설정 파일 형식, 6.게임, 7.개념,규약, 8.관리자 명령어
- 설명서 구조와 sysnopsis 읽는 법 1.NAME 이름과 한줄 설명, 2.SYNOPSIS 사용형식, 3.DESCRIPTION 자세한 설명, 4.OPTIONS 옵션 목록, 5.FILES 관련 파일 경로, 6.EXAMPLES 사용 예시, 7.SEEALSO 관련설명서
- SYNOPSIS의 기호 [ ] 생략가능, ... 여러개 올 수 있음, a | b 둘중 하나, 굵은 글씨 그대로 입력, 밑줄 글씨 내값으로 바꿔서 입력
- 빠르게는 --help, 정확하게는 man을 사용하는 경우가 많다.
- source.list는 폴더 이름인데 어떻게 man 명령어를 사용할 수 있을까? man은 명령어 설명서 라는 이름 때문에 헷갈리기 쉬운데 명령어만 다루는것이 아니다. 리눅스 설명서 문서 전체를 모아 둔 시스템이고 명령어는 그중 한종류일뿐
- man은 명령어를 실행하는 것이 아닌 문서를 찾아서 보여줌  man 5 sources.list 를 치면 이름이 sources.list라는 설명서 문서 파일을 5번 섹션 폴더에서 찾아 보여줌 /usr/share/man/man5/sources.list.5.gz 라는 문서를 찾아서 풀어서 화면에 보여준다.
- 설정파일을 고치다 형식이 궁금해지면 경로를 빼고 파일 이름만 넣어서 man 5 파일이름 을 시도해볼수도 있다.
## 명령어
```bash
man ls, man dpkg, man apk 
```

## 확인
- `man passwd` 1번 비밀번호를 바꾸는 명령어에 대한 설명
- `man 5 passwd` 5번 /etc/passwd 의 파일 형식
- `man 1 uname` uname 명령어 설명
- `man 2 uname` 그 명령어가 내부에서 부르는 uname() 시스템 콜 설명
- `man -k` 이름과 설명에서 키워드로 검색
- `man -f` 그 이름의 설명서가 어디 섹션에 있는지 한줄 요약
- `man -w ` 메뉴얼 파일의 실제 경로 위치
- `man -a` 모든 섹션의 설명서를 차례로 보여줌
- `man 5 source.list` 저장소 설정 파일 형식
- `man 5 fstab` 디스크 마운트 설정
- `sudo mandb` 검색용 데이터베이스 갱신 (man 갱신)
- `sudo unminimize` 지워진 설명서 문서 복원
- `sudo apt install man-db` man 프로그램이 없을때 man 설치
- `/usr/share/man/` 설명서 폴더
