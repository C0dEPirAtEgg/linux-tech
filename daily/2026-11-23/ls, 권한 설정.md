## 정리
- ls는 디렉터리 안에 있는 파일과 폴더의 목록, 그리고 각 파일의 정보(권한, 소유자, 크기, 시간)을 보여줍니다.
- 내부적으로 두 단계로 동작 1. 디렉터리를 열어서 안에있는 이름 목록을 읽음 2.-l 같은 자세한 정보가 필요하면 파일마다 정보를 조회함
- 파일 종류에는 - 일반파일, d 디렉터리, l 심볼릭 링크, c 문자장치, b 블록장치(디스크),   s 소켓, p 파이프
- rwxr-xr-x 권한에서 3글자씩 끊어서 첫번째 3글자인 rwx는 소유자 권한, 두번째 3글자인 r-x는 그룹 권한 세번째 3글자인 r-x는 나머지 사용자 권한
- r은 읽기 권한, w는 쓰기 권한, x는 실행 권한
- 파일에서 rwx는 파일의 내용에 대한 권한이고, 폴더에서 rwx는 폴더 안에 이름 목록에 대한 권한이다.
- 파일에서의 r 내용 읽기(cat), w 내용 수정(덮어쓰기, 추가), x 실행                                 폴더에서의 r 안에 이름 목록보기(ls), w 안에 파일 만들기,이름 바꾸기, 지우기 (x가 필요하다), x 들어가기 안에 파일 접근하기(cd, 경로통과)
- 폴더는 파일이름이 적힌 "목표록"이고 파일은 "실제 내용물"이다
- 폴더의 r 목표록을 읽을 수 있음 폴더의 w 목표록에 이름을 쓰고 지울수 있음 폴더의 x 목표록을 통해 실제 파일까지 접근할 수 있음
- SetUID(rws) 누가 실행하든 파일의 소유자 권한으로 실행됨, SetGID(rws) 그룹권한으로 실행 또는 폴더 안에 만든 파일이 그 폴더의 그룹을 따라감 sticky bit(rwt) 모두가 사용 할 수 있지만 자기 파일만 지울 수 있음
- 날짜 표시 규칙 최근 6개월 이내 (Nov 24 00:00) 시간 사용 6개월 이후 (May 30 2024) 년도 사용
- 폴더의 크기 4096은 안에든 파일 용량이 아니라 폴더 정보 자체의 크기입니다. 폴더 안에 10G가 들어가 있어도 ls -l은 4096으로 보여줌 du -sh /var/log*
- du 파일과 폴더가 실제로 얼마나 차지하는지 계산하는 명령어 
- 실행 파일에서 setuid 실행하는 사람과 상관없이 파일 소유자 권한으로 실행 setgid 파일 그룹의 권한으로 실행 폴더에서 setgid 안에 새로 만든 파일 폴더가 폴더의 그룹을 물려받음 sticky bit 쓰기 권한이 있어도 자기 파일만 지울 수 있음
- 특수 권한의 소문자 특수권한, 스티키 있고 실행권한 있음, 대문자 특수권한, 스티키 있고 실행권한 없음
## 명령어
```bash
ls -l
# drwxr-xr-x 2 root root 4096 Nov 24 00:50 dir 
# drwxr-xr-x 파일종류(첫글자) + 권한(9글자)
# 2 하드 링크 수
# root 소유자
# root 소유 그룹
# 크기(바이트) 4096
# 마지막 수정시간 Nov 24 00:50
# 이름 a.txt

ls -a, ls -h, ls -F, ls -d, ls -R, ls -i

setuid 4 setgid 2 sticky bit 1
4000 2000 1000

파일 내용 읽기 파일 r + 경로의 모든 폴더 x
파일 내용 수정 파일 w + 경로의 모든 폴더 x
파일 실행 파일 x +(폴더 x)
스크립트 실행 파일 r + x +(폴더 x)
폴더 안 목록 보기 폴더 r + (자세히 보려면 x도)
폴더에 들어가기 폴더 x
파일 만들기, 지우기, 이름 바꾸기 폴더 w + x (파일권한과 무관)

```

## 확인
- `ls -l`  파일 형식 자세히 보기
- `ls -a` 숨긴 파일 보기
- `ls -h` 크기를 사람이 읽기 쉽게(30K, 1.2G)
- `ls -F` 파일의 종류 표시를 이름뒤에 붙임 (dir /, link @, 실행파일 *)
- `ls -d` 폴더 자체의 정보
- `ls -i` inode번호
- `ls -R` 하위폴더 전부
- `ls -t` 수정 시간 순
- `ls -S` 크기 순
- `ls -ltr /var/log` 방금 기록이 쌓이고 있는 로그확인 
- `ls -lt /etc | head` 최근에 수정된 파일
- `ls -lct` 정보 변경 시간
